Lần nổ trên bamf đúng với quan hệ MR-A1, nhưng không phải lỗi theo hợp đồng của bamf.

## 2. Shim so với client chính thức

Web UI của bamf đăng nhập local bằng đúng hai request shim gửi (`web/src/app/login/page.tsx:97–131`):

| Bước | Web UI | `login_shim.py` |
|---|---|---|
| 1 | `POST /api/v1/auth/local/authorize`, JSON `email, password, code_challenge, code_challenge_method: 'S256', state` | cùng endpoint, cùng năm trường, JSON |
| 2 | `POST /api/v1/auth/token`, form `grant_type: 'authorization_code', code, code_verifier` | cùng endpoint, cùng ba trường, form |
| Lấy | `tokenData.session_token` | `session_token` |

Web UI gửi thêm `credentials: 'include'` để trình duyệt giữ cookie; shim không cần cookie vì EvoMaster gửi token trong header.
Chưa lặp lại bộ ba bằng token lấy từ web UI chạy thật: cần dựng frontend Next.js.
