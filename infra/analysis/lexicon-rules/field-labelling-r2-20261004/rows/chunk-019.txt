desc: Adds a message to the given conversation. This operation can be only performed on behalf of a user who is already a member of the conversation. OauthScopes: WRITE_CONVERSATIONS, CREATE_CONVERSATIONS_CONTENT
- path:convId string
- body:attachments array<string>
- body:content string
- body:formMetaData string
- body:subject string
